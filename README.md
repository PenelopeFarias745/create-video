# Criador de Vídeos

Projeto criado com cv2 e os para criar vídeos usando um conjunto de imagens.

---
## 📚 Aprendizados
- Uso das bibliotecas os e cv2
- Manipulação e identificação de arquivos de imagem
- Uso de funções como "VideoWriter()" e "imread()" para criação de vídeos


## ⚙️ Funcionalidades
- Agrupa um conjunto de arquivos de imagem, transformando-o em um único arquivo de vídeo
- É possivel alterar a ordem das imagens no "range()" do loop for, criando um por ou nascer do sol.

## 🛠️ Stack
Informe as tecnologias, bibliotecas e frameworks utilizados. Exemplos:

- Python
- Bibliotecas os e cv2
